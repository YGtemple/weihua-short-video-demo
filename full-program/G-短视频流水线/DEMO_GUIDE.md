# G 卫华短视频流水线 · 提交与演示指南

## 推荐提交形态：可运行程序

提交包含全部源码和五套预制媒体的 ZIP 程序包。评审无需配置任何模型密钥即可演示完整工作流和最终成片。

### Windows 运行

1. 安装 Node.js 22 或更高版本。
2. 完整解压 ZIP，不要直接在压缩包预览窗口中运行。
3. 双击 `启动演示.bat`。
4. 启动器自动执行媒体预检、启动本机服务，并打开 `http://127.0.0.1:8177/?view=workflow`。

也可以进入程序目录后执行 `npm start`。本项目没有第三方 npm 依赖，无需执行 `npm install`。

### 其他运行方式

- macOS / Linux：执行 `sh start-demo.sh`。
- Docker：执行 `docker compose up --build`。Dockerfile 和 Compose 配置已提供；本轮 Windows 验收机没有 Docker，未执行镜像构建，因此正式评审优先使用已实测的 Windows 启动器。

## 三分钟演示动线

1. **九节点工作流**：选择 A《名场面穿越》，说明一句话输入、七阶段产物和最终成片节点。
2. **一键流程演示**：点击「预制流程演示」，节点依次点亮；点击剧本、美术、分镜等节点查看真实落盘产物。
3. **最终版本**：点击「查看最终成片」，播放带字幕的完整 MP4。
4. **差异化预制**：切换 B/C/D/E，展示 6 镜与 7 镜、不同主题与不同成片。
5. **逐镜播放器**：进入工程详情，点击「连续播放逐镜」，展示 SH01 → SH02 的连续切换。
6. **真实接口（可选）**：输入新主题并点击「创建并一键拆解」，说明模板文本、真实图像通道和视频任务包边界。此步骤可能调用付费图像接口，不是预制演示的必要步骤。

## 能力边界

- 五套完整成片是提前制作并内置的演示资产，点击即可播放，不依赖实时生成。
- 自建工程可运行七阶段；文本默认使用模板，美术可调用配置的 OpenAI 兼容图像接口，视频阶段输出逐镜提示词和任务包。
- 自建工程的通用实时视频生成、配音与自动合片尚未接入，不应描述为已具备任意主题即时成片能力。
- `config.local.json` 不进入程序包或公开仓库，避免泄露本机密钥。
